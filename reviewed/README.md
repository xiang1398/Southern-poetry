# 南朝詩四聲逐行校訂（部分校訂本）

원문 412수 각 행 아래 四聲 표기. 이전 버전은 `annotated/`에 그대로 보존.

**이번 판본은 최종 전수 교감본이 아닙니다.** 《廣韻》의 확정 성조에 더해 명백한 부정어 `不`의 문맥과, 같은 작품의 짝수구 압운에서 성조·韻目가 일치하는 확정 압운자 3개 이상의 증거를 사용했습니다. 모든 추가 확정은 `resolutions.json`에 근거와 위치를 남겼습니다.

집계: 총 40365자, 종전 확정 30248, 문맥 확정 387, 압운 확정 156, 미확정 9574 (그중 《廣韻》 미수록 361, 복수 독음 9213).

**《集韻》 주의:** 아직 검증 가능한 《集韻》 전자 원자료를 대량 확보하지 못했으므로 **《集韻》 대조는 완료되지 않았습니다**. 미수록자 361건은 `review_queue.json`의 `needs_jiyun: true`로 표시하고, [中央研究院 小學堂《集韻》](https://xiaoxue.iis.sinica.edu.tw/jiyun)에서 字形·反切·韻目·釋義를 교차 검토해야 합니다. 출처를 확인하지 않은 독음은 보충하지 않았습니다.

압운으로 정한 성조는 韻目이 같다는 조건을 사용한 잠정 판단입니다. 通押·換韻·시구 분절 오류·문맥 異讀을 고려하면 확정이 번복될 수 있으므로 `resolutions.json`의 각 판단을 검토할 수 있도록 했습니다. 平仄 통계를 검증하는 데 평측 대립을 기준으로 독음을 고르지 않았습니다.

- `southern_poetry_reviewed.txt`: 원문 바로 아래 교감 성조 표기
- `southern_poetry_reviewed.json`: 작품별 JSON
- `resolutions.json`: 기존 □에서 추가 판정한 전수 위치·판정 규칙·근거
- `review_queue.json`: 아직 □인 모든 토큰과 《廣韻》 독음 후보·간단한 釋義
- `summary.json`: 방법과 집계

《廣韻》 데이터: [untunt/QYS4MCPDict](https://github.com/untunt/QYS4MCPDict), `all_chars.tsv`, `all_rimes.tsv`.
