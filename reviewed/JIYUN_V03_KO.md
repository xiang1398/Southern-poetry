# 《集韻》 대조 1차 보충 (v0.3)

이 판본은 v0.2 TXT를 바탕으로 《集韻》에서 성조별 권에 字頭가 확인된 글자를 추가 표기한 **부분 교정본**이다.

- 원문: [Kanripo 《集韻》](https://github.com/kanripo/KR1j0057), 四庫全書本 전사, 卷1–4 平聲, 卷5–6 上聲, 卷7–8 去聲, 卷9–10 入聲.
- 추가 판정: 33회 / 10종; 平 24, 上 0, 去 5, 入 4.
- 잔여 □: 9558개 (v0.2 대비 33개 감소).

**검증 한계:** 동일한 글자가 특정 권에서 字頭로 나타나는 것을 확인한 것이며, 모든 시구의 문맥적 뜻과 字形異體까지 전수 확인한 것은 아니다. 《集韻》에서 복수 독음이 있는 글자는 단일 권 발견만으로 판정하지 않는다. 《集韻》은 宋代 韻書이므로 六朝 시인의 당대 음가를 그대로 입증하지 않는다. 아래 `jiyun_resolutions.json`의 각 기록은 후속 문헌학적 교감 대상이다.

- `southern_poetry_reviewed_v03.txt`: 각 시구 밑 성조 표기
- `jiyun_resolutions.json`: 《集韻》에 의해 추가된 토큰별 판정 위치 및 권별 출처
- `summary.json`: 집계
