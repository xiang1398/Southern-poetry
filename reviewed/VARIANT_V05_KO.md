# 異體字·簡繁字形 확대 대조: v0.5

## 판정 기준

《廣韻》 원본 `all_chars.tsv` 字頭와 `all_rimes.tsv` 四聲을 재대조하였다. OpenCC의 `STCharacters`·`TSCharacters` 및 대만·홍콩 異體字, 일본 신구자체 변환 자료를 참고하되, **한 간체에 여러 正體가 대응하는 경우를 뜻 구분 없이 합치지 않았다**. 복수 독음의 경우 □를 유지하였다. OpenCC도 이 원칙을 ‘能分則不合’로 설명한다.

이번에 기존 □에서 새로 확정한 글자는 42종, 55회다. 남은 □는 9455개다.

## 보류 원칙

- `風`의 平/去, `長`의 平/上/去처럼 실제 복수 독음이 확인되는 경우는 글자형 대응만으로 판정하지 않는다.
- `復`·`複`·`覆`처럼 한 간체에서 의미가 다른 정체자로 갈라지는 경우, 詞義를 확인하기 전에는 합치지 않는다.
- 사전의 字頭와 釋義에 나오는 글자를 구별하며, 기존 《集韻》 판정은 별도의 잠정 층위로 유지한다.
