# 성조·평측 주석 (2026-10-08 재구축)

원래 `data/southern_candidates.json`의 412개 레코드에 직접 `tone_annotations`를 추가했다. `content`, 원본 ID, 제목, 작가, 선정·출처 필드는 보존했다. 412개는 원본 레코드 수이며, 한 레코드에 여러 수가 묶인 작품도 있으므로 낱시 412수와 동일한 뜻으로 쓰지 않는다.

## 읽는 법

각 `tone_annotations` 원소는 `content`의 같은 인덱스에 대응한다. `four_tones`에는 平·上·去·入, `pingze`에는 平·仄을 쓴다. **문자열 길이와 위치는 원문과 같다.** 구두점·공백은 유지한다. 【…】 등 소제목·설명은 `excluded_spans`에 기록하고 주석 문자열에서도 그대로 보존한다. 원문 결자는 원문을 고치지 않고 주석에서 □로 표시한다.

`data/southern_candidates_tones.txt`는 시구 → 사성 → 평측의 순서로 읽을 수 있는 표시용 파일이다. 분석용 원본은 JSON이다.

## 판독 순서

1. 《廣韻》의 글자·소운·반절·석의를 확보하고, 간화자와 고자·이체자 대응을 검색용으로 연결했다. 원문 자체를 번체로 바꾸지 않았다. 두 《廣韻》 데이터는 같은 운서의 전사본이므로 서로 독립된 역사적 증거라고 계산하지 않는다.
2. 확보한 항목에 독법이 하나면 `single_reading`, 독법은 여럿이어도 성조가 같으면 `single_tone`으로 표시한다. 사성이 여러 가지여도 모두 仄이면 사성은 □, 평측은 仄으로 남긴다.
3. 뜻·품사·어휘·시구에 따라 `context_semantic`, `context_phrase`, `context_exact`로 복원한다. 적용한 규칙과 해당 시구·반절 항목은 `decisions.json`에 남긴다. 이는 문맥 판독이지, 모두 원전에 독음 주기가 있다는 뜻은 아니다. 같은 뜻의 이독을 문맥만으로 고를 수 없으면 보류한다. 不·且·羽翼 등 통행 독법으로 복원한 경우도 그 사실과 다른 후보를 기록했다.
4. 가까운 짝수구 말자 중 서로 다른 두 글자 이상이 같은 《廣韻》 성조·운목을 지지하는 경우에만 `rhyme_local`을 사용한다. 소제목·시구 길이 변화에서 묶음을 끊는다. 압운으로 고른 글자를 다시 압운 판독의 근거로 사용하는 연쇄 추론은 하지 않는다. 운목이 다른 통운·환운은 자동 확정하지 않는다.
5. 《廣韻》 전사에서 찾지 못한 자형은 《集韻》 10권의 글자 항목·반절·석의를 확인했다. 본문 어딘가에 글자가 나타난다는 이유나 그 권의 성조만으로 판정하지 않는다. 실제 항목이 확인된 보충 자료는 `supplements.json`에 URL과 발췌를 남긴다. 漢典의 운서·자형 자료도 교차 확인했다.

爲는 하다·되다·삼다 平, 수혜·원인·목적 去로 나누고, 爲…所… 같은 피동은 통행 平 독법을 반영했다. 復는 다시·또 去, 돌아옴·왕복 入으로 판독한다. 魚復는 사용자가 지정한 去를 별도 기록한다. 間은 공간의 사이 平, 사이를 가르거나 섞어 놓는 동사 去로 나눈다. 이전에 平으로 처리된 倏은 式竹切 入으로 바로잡았다.

## 범위와 한계

《廣韻》·《集韻》의 분류를 기준으로 한 복원이며 남조 시인의 개별 실현음을 직접 증명하지 않는다. 같은 뜻의 사성 이독, 문장 해석이 갈리는 용례, 불확실한 자형은 □로 남겨 `unresolved.json`에 모았다. 원문 중복·오자·시별 연대와 지역, 작품 선정은 이번 작업에서 고치지 않았다. 평측 배열에 맞추어 독음을 고르는 규칙은 없다.

이전 `analysis/`, `annotated/`, `reviewed/`의 성조 분석·중간 판독·통계 파일은 최신 브랜치에서 삭제했다. 기존 분석 통계를 새 주석에 맞춘 결과처럼 재사용하지 않는다. 원문 스냅샷과 선정 자료는 유지한다.

## 재현

```bash
python tools/annotate.py
```

Python 표준 라이브러리만 필요하다. 사전 스냅샷과 규칙 JSON을 읽어 원문 코퍼스의 주석, 표시용 TXT, 판독 기록, 미확정 목록과 집계를 다시 생성한다. 실행을 반복해도 기존 원문 필드는 바뀌지 않는다. 출처와 사전 스냅샷 식별자는 `data/phonology/sources.json`, 현재 수량은 `summary.json`에 기록한다.
